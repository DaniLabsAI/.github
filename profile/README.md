# Intelligence, distributed.

**DaniLabs — Distributed Accelerated Neural Intelligence**

We’re building AI inference on Bittensor around three priorities:

- **No data retention** — designing for prompts and responses to be processed without being stored after a request.
- **Speed** — optimizing the time from a request to a useful response.
- **Competitive pricing** — making inference cost competitive for developers and applications.

The inference service is in development. Follow the build on **[X / @danilabsai](https://x.com/danilabsai)** and visit **[danilabs.ai](https://danilabs.ai/)**.
